# Прогнози на матч

**Грати: https://aalyoshin.github.io/match-predictions/**

Гра на компанію перед футболом. Кожен дає свій прогноз, після фінального свистка застосунок рахує очки й будує таблицю.

## Як це працює

Спершу вводиш команди та імена учасників. Далі телефон іде по колу: перед кожним прогнозом зʼявляється екран «передай телефон», чужі відповіді ніде не показуються.

Кожен ставить рахунок, автора першого гола, кількість жовтих карток, а також чи буде пенальті та червона.

Після матчу ведучий вводить, що сталося насправді. Автора гола можна звірити автоматично — застосунок порівняє прізвища — і будь-який вердикт виправити тапом.

| Жовті картки з помилкою на одну | 1 |
| Пенальті | 1 |

Максимум — 12 очок.

## Важливо

Усі дані живуть в адресі сторінки, тож за девʼяносто хвилин нічого не загубиться і вкладку можна закрити. Але посилання треба зберегти — без нього прогнози не повернути.

## Як запустити

Завантажити `index.html` і відкрити у браузері. Один файл, без збірки та залежностей.
